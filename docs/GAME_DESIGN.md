# 🎉 Skin Party Island v2 — Game Design Document

> **แนวคิด:** เกาะปาร์ตี้แฟชั่นสำหรับทุกวัย — สะสมไอเท็มสวย ๆ แล้ว **เอาไปอวดบนรันเวย์แฟชั่นโชว์** ให้ทุกคนโหวต
> **หลักการรายได้:** ขายความสวยงาม + ความก้าวหน้า + ความคุ้มค่า — ไม่ขายความได้เปรียบ ไม่มีกล่องสุ่ม

---

## 1. ทำไม v1 ขายไม่ได้ และ v2 แก้อย่างไร

| ปัญหา v1 | สาเหตุ | สิ่งที่ v2 แก้ |
|---|---|---|
| ของไม่น่าซื้อ | เห็นแค่อีโมจิในร้าน, โมเดลเรียบ ๆ | **พรีวิว 3D หมุนได้ทุกชิ้น**, โมเดลละเอียดขึ้นหลายเท่า (มงกุฎ 30+ ชิ้นส่วน, ปีกกระพือได้, ออร่าโคจร) |
| ซื้อแล้วไม่รู้จะใส่โชว์ใคร | ไม่มี "เวทีอวด" | **มินิเกมแฟชั่นโชว์** — ใส่ของตรงธีม/หายาก = คะแนนสูง = ชนะ |
| ไม่อยากซื้อของที่ไม่เคยลอง | ไม่มีลองชุด | **ลองใส่ฟรี 20 วิ** (คนอื่นเห็นด้วย = โฆษณาฟรี) |
| ไม่มีเหตุผลให้กลับมา | ไม่มีความก้าวหน้า | **Party Pass 30 ขั้น**, ภารกิจมือใหม่, ฉายาความสำเร็จ |
| ซื้อแล้วไม่ตื่นเต้น | แค่ข้อความ toast | **ฉากเปิดตัวไอเท็ม** (แสงหมุน + คอนเฟตตี) + **ประกาศทั้งเซิร์ฟ** เมื่อได้ของระดับตำนาน |
| สินค้า Robux น้อย | มีแค่เพชร + 2 Pass | **8 ช่องทางรายได้** (ดูข้อ 5) |

## 2. Core Loop

```
   เก็บดาว ⭐ / มินิเกม 🎮 / รายวัน 🎁
            │  (เหรียญ + XP)
            ▼
   ร้านค้า 3D 🛍️ ──ลองใส่ 👀──▶ ซื้อ 💎 ──▶ ฉากเปิดตัว ✨ + ประกาศเซิร์ฟ 📢
            │
            ▼
   แฟชั่นโชว์ 👗  ธีม = เซ็ตไอเท็ม ──▶ ใส่ตรงธีม = คะแนนโบนัส ──▶ ชนะ 🏆
            │                                         │
            └──── "อยากได้ชุดเซ็ตอื่นเพื่อชนะธีมหน้า" ◀──┘
```

**จุดสำคัญ:** ธีมแฟชั่นโชว์ 8 ธีม = 8 เซ็ตไอเท็ม → ทุกรอบจะมีผู้เล่นที่ "อยากได้เซ็ตนั้น" เกิดขึ้นเองโดยธรรมชาติ

---

## 3. มินิเกม (สลับกันทุก ~1.5 นาที)

### 👗 แฟชั่นโชว์ (ตัวขายของหลัก)
1. ประกาศธีม เช่น "🚀 นักบินอวกาศ" → ผู้เล่นถูกพาไปหลังเวที
2. **40 วิแต่งตัว** — ปุ่ม "เปิดตู้เสื้อผ้า" เปิดร้านที่แท็บชุดเซ็ตทันที (ลองได้ แต่ขึ้นเวทีต้องเป็นของจริง)
3. เดินแบบทีละคนบนรันเวย์ไฟวิบวับ — ผู้ชมกดโหวต ⭐1–5
4. **คะแนน = ดาวเฉลี่ย + 0.4 × ของตรงธีม + โบนัสความหายาก**
5. Top 3 ขึ้นโพเดียม 🥇🥈🥉 + ประกาศชื่อผู้ชนะทั้งเซิร์ฟ

### 🎨 พื้นสีวิบวับ (เกมสนุกล้วน ๆ สำหรับเด็กเล็ก)
10 เวฟ ยืนบนสีที่ประกาศ ตกสไลม์ = กลับเกาะ (ไม่มีการตาย) ได้เหรียญทุกเวฟที่รอด

## 4. ไอเท็ม (75 ชิ้น, 7 หมวด, 8 เซ็ตธีม)

**หมวด:** สกิน • หมวก • **ปีก (ใหม่, กระพือได้)** • สัตว์เลี้ยง • หางวิ้ง • ออร่า (อนุภาค/โคจร) • **ฉายาเหนือหัว (ใหม่)**

| เซ็ต | ความหายาก | สกุลเงิน | ช่องทาง |
|---|---|---|---|
| 🍭 แคนดี้ป๊อป | ธรรมดา–หายาก | 🪙 | หาฟรีในเกม |
| 🌊 โอเชียนดรีม | หายาก | 🪙 | หาฟรีในเกม |
| 🚀 นักบินอวกาศ | มหากาพย์ | 🪙 / Bundle R$ | ฟรี (ต้องขยัน) หรือซื้อเซ็ต |
| 🎃 ผีน้อยน่ารัก | มหากาพย์ | 🪙 / Bundle R$ | ฟรี (ต้องขยัน) หรือซื้อเซ็ต |
| 🧚 สวนนางฟ้า | ตำนาน | 💎 / Bundle R$ | เพชร |
| 🤖 นีออนไซเบอร์ | ตำนาน | 💎 / Bundle R$ | เพชร |
| 👑 ราชวงศ์ทองคำ | เทพนิยาย | 💎 / Bundle R$ | เพชร |
| 🌈 ความฝันสายรุ้ง | เทพนิยาย | Party Pass | พรีเมียมพาส |

นอกจากนี้: ไอเท็มพื้นฐาน 10 ชิ้น, VIP 4 ชิ้น, Starter Pack 3 ชิ้น, ฉายา 12 แบบ (4 แบบได้จากความสำเร็จ เช่น ชนะพื้นสี 10 ครั้ง)

**เทคนิคทำให้ของ "ดูแพง":**
- ระดับตำนาน/เทพนิยายมี **ประกายอนุภาค + แสง** อัตโนมัติ
- ของที่ขยับได้ (ปีกกระพือ, ใบพัด, ออร่าโคจร, หางสายรุ้งไหล) — ดูมีชีวิต
- ฉายาระดับสูงมี **แสงวิ่ง** บนตัวอักษร

## 5. โมเดลรายได้ (8 ช่องทาง)

| # | สินค้า | ประเภท | ราคาแนะนำ | จิตวิทยา |
|---|---|---|---|---|
| 1 | 🚀 **Starter Pack** | Dev Product (ครั้งเดียว) | 99 R$ | ข้อเสนอคุ้มสุด + นับถอยหลัง 72 ชม. เด้งหลังผู้เล่นซื้อของชิ้นแรก (ตัวแปลงผู้เล่นเป็นผู้จ่ายเงินอันดับ 1) |
| 2 | 🎫 **Party Pass พรีเมียม** | Game Pass (รายซีซั่น) | 399 R$ | ได้เซ็ตเทพนิยายครบ + เพชร 300 คืน → "คุ้มกว่าซื้อเพชร" + รายได้ซ้ำทุกซีซั่น |
| 3 | ⏩ ข้ามขั้น Pass | Dev Product | 99 R$ | ใกล้จบซีซั่นแล้วยังไม่ถึงของ |
| 4 | 👑 **VIP** | Game Pass | 249 R$ | สถานะ: ฉายา VIP, ป้ายแชท, ปีกฟีนิกซ์, เหรียญ +20% |
| 5 | 🪙 เหรียญ x2 | Game Pass | 149 R$ | สำหรับสายสะสม (ไม่ช่วยชนะ) |
| 6 | 💎 เพชร 5 ขนาด | Dev Product | 49–999 R$ | Tag "ยอดนิยม/คุ้มสุด" นำสายตาไปแพ็กกลาง-ใหญ่ |
| 7 | 🎽 **ชุดเซ็ตครบ** | Dev Product | 199–599 R$ | ลด 35–45% + เพชรโบนัส, ผูกกับธีมแฟชั่นโชว์ |
| 8 | ลดราคารายวัน | (กระตุ้นใช้เพชร) | — | 6 ชิ้นลด 30% เปลี่ยนทุกวัน |

**Funnel การจ่ายเงิน:**
เข้าเกม → ภารกิจมือใหม่ (ได้เหรียญ+เพชรฟรี) → **ซื้อชิ้นแรกด้วยเหรียญ** (ฉากเปิดตัว) → เด้ง Starter Pack → แฟชั่นโชว์ (เห็นคนอื่นใส่ของสวย + ประกาศเซิร์ฟ) → Party Pass / Bundle

**ความปลอดภัยของระบบเงิน:**
- ราคาและสิทธิ์ตรวจที่เซิร์ฟเวอร์ทั้งหมด, Rate-limit ทุก Remote
- `ProcessReceipt`: กันให้ของซ้ำด้วย PurchaseId, **ย้อนข้อมูลกลับ** ถ้าบันทึกไม่สำเร็จ
- ส่งข้อมูลเศรษฐกิจเข้า **Creator Dashboard (AnalyticsService)** — ดูได้ว่าเหรียญ/เพชรไหลเข้าออกทางไหน และ onboarding funnel หลุดตรงไหน

## 6. ความเหมาะสมกับทุกวัย ✅
- ไม่มีกล่องสุ่ม/กาชาที่ใช้เงินจริง — **เห็นของ 3D และลองใส่ได้ก่อนซื้อทุกชิ้น**
- ไม่ pay-to-win — มินิเกมพื้นสีไม่ได้รับผลจากไอเท็มเลย, แฟชั่นโชว์คะแนนหลักมาจากโหวต
- มีหน้ายืนยันก่อนใช้เหรียญ/เพชรทุกครั้ง
- ไม่มีความรุนแรง ตกแล้วเด้งกลับเกาะ
- ไม่มีแชทพิเศษ/การแลกเปลี่ยนระหว่างผู้เล่น (ลดความเสี่ยงหลอกลวง)

## 7. ตัวชี้วัด (ดูใน Creator Dashboard)

| ตัวชี้วัด | เป้าหมายเริ่มต้น | ถ้าต่ำกว่าเป้า ให้ปรับ |
|---|---|---|
| D1 Retention | ≥ 25% | ภารกิจมือใหม่ / รางวัลรายวัน |
| D7 Retention | ≥ 8% | รางวัล Party Pass ฝั่งฟรี |
| เวลาเล่นเฉลี่ย | ≥ 15 นาที | ความถี่มินิเกม, ราคาเหรียญ |
| % ซื้อของชิ้นแรก (เหรียญ) | ≥ 60% | ลดราคาของ Common |
| Payer Conversion | 1.5–3% | Starter Pack / ข้อเสนอ |
| ARPDAU | ติดตามรายสัปดาห์ | ราคา Bundle / Pass |
