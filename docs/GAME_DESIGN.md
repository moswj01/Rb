# 🎉 Skin Party Island — เอกสารออกแบบเกม (Game Design Document)

> **แนวคิดในประโยคเดียว:** เกาะปาร์ตี้สีพาสเทล ที่ผู้เล่นทุกวัยมาเก็บดาว เล่นมินิเกมสั้น ๆ แล้วเอาเหรียญไปแต่งตัวด้วยสกิน หมวก หางวิ้ง สัตว์เลี้ยง และออร่า — **ขายความน่ารัก ไม่ขายความได้เปรียบ**

---

## 1. กลุ่มเป้าหมาย: "เล่นได้ทุกวัย"

| กลุ่ม | สิ่งที่เขาชอบ | เกมตอบโจทย์ยังไง |
|---|---|---|
| เด็กเล็ก (6–9) | สีสด ปุ่มใหญ่ ไม่ต้องอ่านเยอะ | อีโมจิทุกปุ่ม, เก็บดาวแค่เดินชน, ไม่มีการตาย/เลือด |
| เด็กโต (10–14) | สะสม อวดเพื่อน แข่งชนะ | ระดับความหายาก 5 ขั้น, มินิเกมมีผู้ชนะ, ลีดเดอร์บอร์ด "ชนะ" |
| วัยรุ่น/ผู้ใหญ่ | แต่งตัวเท่ ๆ เล่นชิลกับครอบครัว | สกินระดับตำนาน/เทพนิยาย, ปุ่ม "พักมินิเกม" เดินเล่นชิล |

**ข้อห้ามที่ตั้งไว้ตั้งแต่ต้น (ความปลอดภัยสำหรับเด็ก):**
- ❌ ไม่มีกล่องสุ่ม/กาชาที่จ่ายเงินจริง — ทุกชิ้น **เห็นของก่อนซื้อ** และซื้อตรง ๆ
- ❌ ไม่มี pay-to-win — ของที่ขายทั้งหมดเป็น "ความสวยงาม" ไม่มีผลต่อมินิเกม
- ❌ ไม่ล็อกของแบบ "หมดแล้วหมดเลย" (FOMO) — โปรลดราคารายวันแค่ "ลดราคา" ของทุกชิ้นซื้อได้ตลอด
- ✅ มีหน้ายืนยันก่อนซื้อทุกครั้ง กันเด็กกดพลาด
- ✅ มินิเกม "ตก" = เด้งกลับเกาะ ไม่มีความรุนแรง

## 2. Core Loop (วงจรหลักของเกม)

```
 ┌──────────────┐     ┌───────────────┐     ┌────────────────┐
 │ เก็บดาว ⭐    │ ──▶ │ ได้เหรียญ 🪙   │ ──▶ │ ซื้อ/ใส่สกิน 🛍️ │
 │ เล่นมินิเกม 🎨 │     │ รางวัลรายวัน 🎁 │     │ อวดเพื่อน 😎     │
 └──────────────┘     └───────────────┘     └────────────────┘
        ▲                                            │
        └──────────── อยากได้ชิ้นถัดไป ◀──────────────┘
```

- **เซสชันสั้น (5 นาที):** เก็บดาว ~20 ดวง + เล่น 1 รอบ ≈ 250 เหรียญ → ซื้อของ Common ได้ 1–2 ชิ้นทันที (รู้สึกได้รางวัลเร็ว)
- **เซสชันยาว (30 นาที+):** สะสมไปซื้อของ Epic (900–1,600 เหรียญ)
- **ระยะยาว:** สะสมครบ 43 ชิ้น / ล่าของ Legendary-Mythic (เพชร)

## 3. ระบบในเกม

### 3.1 เกาะล็อบบี้ 🏝️
- เกาะกลม ต้นไม้ลูกกวาด 18 ต้น ทะเลเดินได้ (ไม่จมน้ำ)
- **ดาว ⭐** 35 ดวง ลอยหมุนทั่วเกาะ = 5 เหรียญ, เกิดใหม่ทุก 4 วิ
- **ดาวยักษ์สายรุ้ง 🌈** (7%) = 25 เหรียญ — สร้างจังหวะ "ว้าว!"
- **ร้านสกิน 🛍️** (ProximityPrompt) และ **กล่องของขวัญยักษ์ 🎁** (รางวัลรายวัน)

### 3.2 มินิเกม "พื้นสีวิบวับ" 🎨 (ทุก ~25 วินาที)
1. ทุกคนถูกวาร์ปขึ้นอารีน่าลอยฟ้า พื้น 8×8 ช่อง สุ่ม 6 สี
2. เกมประกาศ "ไปยืนบนสี **ฟ้า**!" พร้อมแถบเวลา
3. หมดเวลา → พื้นสีอื่นหายไป → ใครตกก็ลงบ่อสไลม์แล้วเด้งกลับเกาะ
4. 10 เวฟ เวลาลดลงเรื่อย ๆ (5 วิ → 1.6 วิ)
5. รอดทุกเวฟ = **ชนะ** (+120 เหรียญ, +1 ชนะในลีดเดอร์บอร์ด)

**ทำไมเหมาะกับทุกวัย:** กติกาเข้าใจได้ใน 3 วินาที (แค่ดูสี), ได้เหรียญทุกเวฟที่รอด (แพ้ก็ยังได้ของ), กำแพงใสกันตกขอบ, กด "🎮 พัก" ได้ถ้าไม่อยากเล่น

### 3.3 รางวัลรายวัน 🎁
7 วันต่อเนื่อง: 50 → 80 → 120 → 💎5 → 200 → 300 → 💎20+300 แล้ววนใหม่ (หายเกิน 48 ชม. รีเซ็ต)

### 3.4 โค้ด 🎟️
ใช้แจกในโซเชียลเพื่อดึงคนกลับมา (`WELCOME`, `PARTYTIME`, `SKINPARTY2026`) แก้ได้ใน `Config.lua`

## 4. ไอเท็ม & สกิน (43 ชิ้น, 5 หมวด)

| หมวด | ตัวอย่าง | วิธีแสดงผล |
|---|---|---|
| 🎨 สกินตัวละคร (13) | สตรอว์เบอร์รี่, หุ่นยนต์จิ๋ว, ลาวาเดือด, ทองคำแท้, สายรุ้งวิบวับ | เปลี่ยนสี+วัสดุของร่างกาย (หัว/ตัว, แขน, ขา คนละสี) |
| 🎩 หมวก (9) | หมวกปาร์ตี้, หูแมว, หมวกใบพัด (หมุนได้!), มงกุฎเพชร, วงแหวนนางฟ้า | สร้างจาก Part หลายชิ้น เชื่อมกับหัว |
| 🌈 หางวิ้ง (7) | ฟองสบู่, เปลวไฟ, ดาวตก, สายรุ้งพาดฟ้า | Trail ไล่สี |
| 🐾 สัตว์เลี้ยง (8) | สไลม์ดุ๊กดิ๊ก, ผีน้อยขี้อาย, จานบินจิ๋ว, คิวบี้สายรุ้ง | ตัวกลม ๆ มีตา+แก้มแดง ลอยตามผู้เล่น |
| ✨ ออร่า (6) | ประกายดาว, หิมะโปรยปราย, ไฟลุกโชน, เวทมนตร์ม่วง | ParticleEmitter / Fire / Sparkles |

**ความหายาก & ราคา**

| ระดับ | สี | ราคา | สกุลเงิน |
|---|---|---|---|
| ธรรมดา | เทา | 100–300 | 🪙 เหรียญ |
| หายาก | ฟ้า | 300–650 | 🪙 เหรียญ |
| มหากาพย์ | ม่วง | 900–1,600 | 🪙 เหรียญ |
| ตำนาน | ทอง | 45–80 | 💎 เพชร |
| เทพนิยาย | ชมพู | 100–150 | 💎 เพชร / VIP |

> ✅ **ของ 30 จาก 43 ชิ้น (+สกินเริ่มต้นฟรี) ซื้อได้ด้วยเหรียญที่หาในเกมฟรี** — คนไม่เติมก็สนุกได้เต็มที่
> 💎 เพชรก็หาฟรีได้จากรางวัลรายวัน (25 เพชร/สัปดาห์) และโค้ด

**ร้าน "ลดราคาวันนี้" ⭐** — สุ่ม 4 ชิ้นลด 25% ทุกวัน 07:00 น. (เวลาไทย) ทำให้มีเหตุผลกลับมาเช็กร้านทุกวัน

## 5. โมเดลรายได้ (Robux)

| สินค้า | ประเภท | ราคาแนะนำ | ได้อะไร |
|---|---|---|---|
| ถุงเพชรจิ๋ว | Developer Product | 49 R$ | 💎 40 |
| กล่องเพชร | Developer Product | 119 R$ | 💎 110 (+10%) |
| หีบเพชร | Developer Product | 249 R$ | 💎 250 (+25%) |
| ภูเขาเพชร | Developer Product | 499 R$ | 💎 600 (+50%) |
| 👑 VIP ปาร์ตี้ | Game Pass | 199 R$ | สกิน "ราชาปาร์ตี้" + ออร่า VIP + ป้าย VIP บนหัว + แท็กแชท |
| 🪙 เหรียญ x2 | Game Pass | 149 R$ | เหรียญจากดาวและมินิเกม ×2 ตลอดไป |

**ทำไมคนจะจ่าย (โดยไม่ต้องบังคับ):**
1. **อวดได้** — สกิน/สัตว์เลี้ยง/ออร่าเห็นชัดในโลก + ป้าย VIP + แท็กแชท
2. **ประหยัดเวลา** — เหรียญ x2 สำหรับคนที่อยากสะสมเร็ว (แต่ไม่ช่วยชนะมินิเกม)
3. **ความรู้สึกคุ้ม** — แพ็กใหญ่โบนัสมากกว่า
4. **ซัพพอร์ตผู้สร้าง** — ข้อความขอบคุณหลังซื้อ

**ความปลอดภัยของระบบเงิน:**
- `ProcessReceipt` เก็บ PurchaseId กันให้ของซ้ำ และ **บันทึก DataStore สำเร็จก่อน** ถึงจะยืนยันกับ Roblox
- ราคาและการหักเงินคำนวณที่เซิร์ฟเวอร์เท่านั้น (client ส่งแค่ "อยากได้ไอเท็ม ID นี้")
- Rate-limit Remote ทุกตัว
