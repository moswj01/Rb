## Part A — Environment Keyframes

### KF-01 · Village Square at Golden Hour (จัตุรัสหอนาฬิกา ยามแดดทอง)

| ฟิลด์ | Brief |
|---|---|
| **จุดประสงค์** | Key art หลักของเกม — "ความอบอุ่นของบ้าน" ภาพที่ผู้เล่นเห็นครั้งแรกหลังเกิด |
| **Camera** | ระดับสายตาผู้เล่น (สูง ~5 studs) ยืนที่ Player spawn `(0,0,60)` มองไปทางเหนือ (−Z) · เลนส์ ~35 mm · หอนาฬิกาห่าง 60 studs ยอดแตะ 1/6 บนของเฟรม |
| **เวลา / แสง** | ~17:30 ในเกม (เริ่ม dusk) ดวงอาทิตย์ต่ำทางตะวันตก (ซ้ายของภาพ) ส่องข้ามจัตุรัส แสงพีชทอง `#FFB48A` ผนังด้านตะวันออกสว่าง เงายาวสีม่วงอมฟ้าทอดไปทางขวา; หน้าต่างบางบานเริ่มติดไฟ `#FFC878`; ไฟหลังหน้าปัดนาฬิกาเพิ่งเปิด |
| **Foreground** | ขอบซ้าย: ผ้ากันสาดลายครีม-แดงของแผงผลไม้ A (ลัง glowberry เรืองฟ้าจาง); ขวา: แผงจุกจิก B ธงราวสามเหลี่ยม; ถนนหิน MainRoad พุ่งจากล่างกลางภาพ |
| **Midground** | หอนาฬิกา (ฐานหินจารึกคำสัญญา, ตัวหอไม้-ปูน, ยอดชนวนแพตช์สีต่าง ๆ, ใบพัดจิ้งจอก); ผู้เฒ่ามาริเบลนั่งม้านั่งหินข้างหอด้านใกล้กล้อง; ซ้ายลึก: ไซโลของร้านอาหารสัตว์; ขวาลึก: ร้านยาเอียงกับปล่องไฟควันเขียว + หม้อยาเรืองเขียว `#96FFAA` |
| **Background** | MainRoad ต่อไปถึงประตูเหนือ (ซุ้มไม้) → แนวป่าเขียวเข้มที่ลาดขึ้น → ยอดต้นไม้ผู้เฒ่าโผล่เหนือป่าในหมอกทอง → หน้าผา Rim จาง ๆ |
| **Life** | Pip วิ่งกับกระดาษวาดรูปสัตว์, นกบินจากหอระฆัง, ควันปล่องไฟ, ฝุ่นแสงลอยในลำแสง |
| **Color key** | Warm Plaster `#EADCC0`, Terracotta `#B7593A`, Oak `#7A5434`, เงา `#56688A`, accent Brew Green `#96FFAA`, Lantern `#FFC878` |
| **Must read** | (1) หอนาฬิกาคือ focal point (2) ถนนนำสายตาสู่ป่า = คำเชิญชวน (3) รู้สึก "ปลอดภัย" |

### KF-02 · River Bridge (สะพานหินข้ามแม่น้ำ)

| ฟิลด์ | Brief |
|---|---|
| **จุดประสงค์** | แสดงแม่น้ำ "เส้นชีวิต" และงานหินของหมู่บ้าน; ภาพ establishing ว่าโลกมีที่มาที่ไป |
| **Camera** | ยืนบนตลิ่งฝั่งตะวันตกใต้สะพาน ~ (115, 18, 30) มองขึ้นทางเหนือ-ตะวันออก ให้เห็นโค้งสะพานด้านข้างและแม่น้ำไหลเข้าหากล้อง · เลนส์ 24 mm มุมต่ำ |
| **เวลา / แสง** | สายราว 10:00 แดดใส ท้องฟ้าฟ้าอ่อน แสงสะท้อนน้ำเป็นลายระยิบบนท้องโค้งสะพาน |
| **Foreground** | หินมอสริมน้ำ (Rock_Moss), เฟิร์น, ผิวน้ำใสเห็นก้อนกรวด, ลูกตุ่นโผล่หัวดมน้ำ (Common, Day — สัตว์ตัวแรกที่ผู้เล่นมักเห็น) |
| **Midground** | สะพานหินโค้งสามช่วง (ช่วงกลางใหญ่) หินแต่ละก้อนมีรอยมือ/ชื่อสลัก, โคมเหล็ก 2 ต้นกลางสะพาน; Pip ยืนพิงราว (ตามตาราง 12:00 ของเขาอยู่หัวสะพาน) |
| **Background** | ทวนน้ำขึ้นเหนือ: ตลิ่งป่าสองฝั่ง แม่น้ำคดหายเข้าไปในหมอก → หน้าผาน้ำตกไกลมากเป็นเส้นขาวบาง ๆ |
| **Color key** | River Teal `#3F8C8C`, Cobble `#9C8E78`, Moss `#3F5B3A`, sky `#9EC9F0`, highlight น้ำ `#BFEAF0` |
| **Must read** | แม่น้ำไหลมาจาก "ที่ไหนสักแห่งทางเหนือ" — กระตุ้นให้อยากไปต้นน้ำ |

| **Must read** | ผู้เล่นต้องรู้ทันทีว่า "เป้าหมายอยู่ตรงนั้น" (Elder Tree) โดยไม่ต้องมี UI |

### CS-01 · Spirit Kitsune — จิ้งจอกวิญญาณ (`spirit_kitsune`, CRE-01)

| ฟิลด์ | Brief |
|---|---|
| ข้อมูลเกม | Spirit · Uncommon · Dusk · Whispering Forest · Personalities: Playful / Curious / Shy · Favorite `spirit_plum` · Dislikes `crystal_grub` |
| Palette | `#F2ECE4` ขนครีมขาว · `#8CC4FF` ปลายหาง/หูด้านใน (สงบ) · `#FFC478` ปลายหาง (ดีใจ), ม่านตา |
| แก่นการออกแบบ | **"แสงหิ่งห้อยนับพันดวงที่รวมเป็นตัว"** — ขนนุ่มเหมือนหมอกแสง ขอบขนโปร่ง (rim) เรืองจาง ๆ ในที่มืด; **หางสามหาง** คือ signature: เรืองตามอารมณ์ ฟ้า = สงบ, ทอง = ดีใจ, ขาวจาง = กลัว |
| Silhouette hook | หูใหญ่ตั้งสามเหลี่ยมมน + หางสามพลิ้วเป็นพัด — ต้องจำได้แม้เห็นแค่หาง |
